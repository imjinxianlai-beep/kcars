# K-Cars CRM：查询与每月更新

网址：https://kcars.vercel.app/

上线启用后，使用管理员交给你的用户名和密码登录。Jonathan 的权限是查询维修记录、导入新数据、查看导入历史。

## 查询记录

在“查询记录”输入车牌或客户姓名，选择车辆，展开发票查看项目和金额。“客户 · 全部车辆”显示这个客户的全部发票，包括早期未关联车辆的记录。

## 每月更新

1. 按原有 AutoCount 导出格式准备 `K Cars.xlsx` 和 `1 World.xlsx`。每份最多 5 MB、10,000 条数据行；可以包含多个工作表。
2. 打开“更新数据”，分别选择两份文件，点击“上传并检查”。此时保存原件和检查结果，尚未新增维修发票。
3. 核对“待导入”数量、明细数和金额。已有发票按原发票号跳过，保留历史数据；免费项目和折扣也会保留。
4. 点击“确认导入…”，再次核对后点击“确认并导入”。这些历史单据按原来的更新规则记为已付款。
5. 在“导入历史”查看结果。需要时可重新打开批次，继续处理待补资料的单据。

缺车牌的单据：查明正确车牌，在待补资料行填写并保存，再确认导入。不要猜车牌。金额不符、同一单据跨工作表重复或客户关联冲突：联系管理员核对源文件，再上传修正后的工作簿。

如果网络中断，先刷新批次结果。再次确认会跳过已经写入的发票，避免重复。查询与导入之外的更改由管理员处理。

密码只通过双方认可的方式交接，不要写在工作簿或共享说明里。
