# K-Cars CRM — Monthly updates

Open https://kcars.vercel.app/ and select **English** in the language menu. Your choice is remembered on this browser. Sign in using your assigned username and password.

1. Export the usual **K Cars.xlsx** and **1 World.xlsx** workbooks from AutoCount.
2. Open **Update data**, select both files, then choose **Upload and check**. This saves the originals and prepares a preview; it does not yet add invoices.
3. Review the number of invoices, line items and total amount. Existing invoice numbers are skipped without overwriting historical records.
4. Select **Confirm import…**, check the summary, then confirm. Imported historical invoices are marked as paid.
5. Check **Import history** for the outcome. Missing plates can be supplied later in the same batch. Other data conflicts should be reviewed with the administrator and corrected in the source workbook.

Each file must be an .xlsx workbook of up to 5 MB and 10,000 data rows. All worksheets, discounts and free items are included. If your connection is interrupted, refresh the batch before retrying; already imported invoices are skipped automatically.

Use **Search records** to find repair history by registration plate or customer name. Your account cannot edit old invoices, delete records or manage accounts.
